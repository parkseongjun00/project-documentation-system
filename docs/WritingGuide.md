# 문서 작성 가이드

---

## 0. 일러두기

이 저장소의 구조화된 Markdown에 적용한다. 문서별 추가 기준은 해당 문서의 일러두기에 적는다.

---

## 1. 문장과 구조

- 제목은 문서의 장과 절에 사용한다. 독립된 요점은 불릿, 비교는 표, 연결된 설명은 짧은 문단으로 쓴다.
- 번호가 필요한 문서는 H2에 장 번호, H3에 절 번호를 붙인다. 시작 규칙은 `0. 일러두기`로 둔다.
- 한 항목에 한 가지 요점을 적고, 실제로 필요한 역할·상태 정보만 표시한다.

---

## 2. 근거와 링크

- 사실, 해석, 제안, 확정된 결정을 구분한다. 확인 결과에 확인 범위와 남은 한계를 적는다.
- 상세 설명은 해당 주제를 관리하는 문서에 둔다. 다른 문서에서는 필요한 만큼 요약하고 상대 링크로 연결한다.
- 문서가 이동하거나 제목이 바뀌면 관련 링크를 확인한다. 항목 순서가 바뀌는 목록에는 표시 번호와 별개의 고정 앵커를 쓴다.
- 이전 판단의 사유와 검증 조건은 보존한다. 새 규칙은 현행 기준에 반영하고, 역사적 판단의 변경은 후속 기록으로 연결한다.
