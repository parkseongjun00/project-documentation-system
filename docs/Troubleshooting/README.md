# 트러블슈팅 기록

---

## 0. 일러두기

반복 조사할 가능성이 있는 문제 하나의 가설과 시도, 실제 결과를 기록한다. 같은 문제를 다시 조사하면 기존 파일에 이어 쓴다.

---

## 1. 기록 방법

1. 문제의 증상, 재현 조건, 환경, 조사 상태를 요약한다.
2. 조사 순서대로 가설, 시도, 결과, 판단을 기록한다. 실행한 시도와 검토만 한 안을 구분한다.
3. 결과에는 해결책이나 중단 이유를 적는다. 확정된 기술 결정은 [개발 노트](../DevNotes/README.md)에 기록하고, 세부 조사 경로는 이곳에 보존한다.
