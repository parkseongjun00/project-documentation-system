# 세션 논의 초안

---

## 0. 일러두기

1. 사용 중인 한 작업 세션만 읽고 쓰는 비영구 메모다.
2. 현재 요청의 검토, 선택지, 제안, 구현 초안과 작업 중 메모를 정리한다.
3. 문서 제목과 일러두기, 고정 목차를 유지하고 현재 요청의 본문을 갱신한다.
4. 확정된 내용은 기준 문서나 보존 기록으로 옮기고 관련 위치를 연결한다.
5. 파일 배정과 갱신은 [세션별 논의 초안 규칙](README.md)을 따른다.
