# 세션 논의 초안

| 항목 | 내용 |
|---|---|
| 소유 세션 | 배정받은 세션 이름 또는 식별자 |
| 이번 요청 | 현재 처리할 요청 |
| 작업 경로 | 이 초안의 저장소 내 경로 |

---

## 0. 일러두기

소유 세션의 작업 중 메모다. 확정 후에는 기준 문서나 보존 기록으로 옮기고 관련 위치를 연결한다.

---

## 1. 이번 요청

목표, 필요한 결정, 작업 범위와 제외 범위를 적는다.

---

## 2. 작업 계획

확인할 자료, 검토할 선택지, 필요한 검증을 적는다.

---

## 3. 작업 결과

확인한 사실, 제안, 확정 사항, 미확인 사항을 구분해서 적는다.

---

## 4. 관련 문서

관련 기준, 조사 자료, 확정 내용을 옮긴 위치를 연결한다.
