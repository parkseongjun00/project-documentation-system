## 0. 일러두기

1. 이 문서는 현재 요청의 논의와 검토를 정리하는 한 세션 전용 초안이다.
2. 0. 일러두기는 고정 운영 규칙이며, 사용자의 명시적 요청 없이는 추가·수정·삭제하지 않는다.
3. 새 요청에서는 1장 이후의 본문만 현재 요청 내용으로 교체한다.
4. 확정 사항·제안·작업 결과·미확인 사항을 구분한다.
5. 작업 전에는 관련 기준 문서와 현재 코드·자산을 다시 확인한다.
6. 관련 문서는 한 불릿에 한 문서만 기록하고, 확인 목적을 한 문장으로 적는다.
7. 사용자가 작업 내용과 확인할 사항을 빠르고 명확하게 파악할 수 있도록, 필요한 정보만 간결하게 기록한다.
