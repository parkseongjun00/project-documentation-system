# 세션별 논의 초안

---

## 0. 일러두기

이 폴더는 현재 요청의 조사, 선택지, 작업 계획, 결과를 적는 세션별 공간이다. [공용 인수인계](../HANDOFF.md)는 다음 작업을 위한 요약을 담는다.

---

## 1. 초안 배정

1. 사용자가 경로를 지정하면 해당 초안을 사용한다.
2. 새 파일이 필요하면 [초안 양식](Template.md)을 복사하고, 세션 식별자와 주제가 들어간 고유한 이름을 쓴다. 예시는 `session-a-scope.md`와 `session-b-workflow.md`다.
3. 파일 상단에 소유 세션과 이번 요청을 적고, 대화에서 작업 중인 경로를 알린다. 같은 이름의 초안이 이미 다른 세션 소유라면 새 이름을 사용한다.
4. 작업 중에는 배정된 파일을 갱신한다. 다른 세션의 파일을 이어서 작업할 때는 담당 변경이나 인계를 명시한다.

---

## 2. 이관과 병행 작업

- 예를 들어 A 세션은 `session-a-scope.md`, B 세션은 `session-b-workflow.md`를 갱신한다.
- 승인된 수정이 공통 기준에 영향을 주면 담당 세션과 범위를 조율한다. 통합을 맡은 세션은 확정된 내용을 적절한 문서에 반영하고, 다음 작업 요약을 인수인계에 적는다.
- 오래 보존할 결정은 [개발 노트](../DevNotes/README.md)에, 상세 기준은 [프로젝트 명세](../ProjectSpec.md)에 기록한다. 지속적으로 참조할 링크는 해당 보존 위치를 가리킨다.
