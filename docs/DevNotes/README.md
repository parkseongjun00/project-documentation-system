# 개발 노트

---

## 0. 일러두기

중요한 판단과 그 이유를 주제별로 보존한다. 작업을 반복할 때 참고할 문제, 제약, 기각 이유, 확인 결과를 남긴다.

---

## 1. 기록 방법

- 기록 제목에는 판단의 주제와 기록일을 적는다.
- 본문은 **문제**, **결정**, **근거**, **검증과 한계** 순서로 작성한다.
- 변경 전 결정의 본문과 검증을 보존하고, 새 판단을 후속 기록으로 추가한다. 영향을 받는 이전 절에 변경 범위와 후속 기록 링크를 적는다.
- 성격이 같은 판단은 주제 파일에 누적한다. 기록 번호와 앵커는 참조에 사용하므로 기존 식별자를 유지한다.
