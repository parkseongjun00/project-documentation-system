## 0. 일러두기

1. 이 문서는 현재 요청의 논의와 검토를 정리하는 한 세션 전용 초안이다.
2. 0. 일러두기는 고정 운영 규칙이며, 사용자의 명시적 요청 없이는 추가·수정·삭제하지 않는다.
3. 새 요청에서는 1장 이후의 본문만 현재 요청 내용으로 교체한다.
4. 확정 사항·제안·작업 결과·미확인 사항을 구분한다.
5. 작업 전에는 관련 기준 문서와 현재 코드·자산을 다시 확인한다.
6. 관련 문서는 한 불릿에 한 문서만 기록하고, 확인 목적을 한 문장으로 적는다.
7. 사용자가 작업 내용과 확인할 사항을 빠르고 명확하게 파악할 수 있도록, 필요한 정보만 간결하게 기록한다.
8. 새 요청으로 본문을 교체할 때는 고정 목차와 ‘작성 안내’로 표시된 인용문을 보존한다.

### 3.2 사용자 확인

> **작성 안내**
>
> 다음 작업을 맡기기 전에 사용자가 확인한다.
>
> - **동작** - 대표 입력이나 원본 자료를 확인했을 때 기대한 결과가 나왔는가?
> - **이해** - 입력이나 근거에서 결과가 어떻게 나왔는지 내 말로 설명할 수 있는가?
> - **구조** - 바뀐 부분이 맡은 역할은 분명하고, 이번 요구에 필요한 만큼 단순한가?

---

### 3.3 검증 결과

> **작성 안내**
>
> 합의한 멈춤 지점에 도달하면 AI가 다음 항목을 정리한다.
>
> - **먼저 볼 위치** - 핵심 변경을 확인할 파일, 함수, 문서나 자료의 위치를 적는다.
> - **다시 확인하는 방법** - 사용자가 같은 동작이나 결과를 확인할 수 있도록 입력과 실행 또는 대조 방법을 적는다.
> - **실제 확인 결과** - 실행 또는 대조에 사용한 조건과 실제 결과를 적는다. 확인하지 못했다면 그 범위와 사유를 적는다.
