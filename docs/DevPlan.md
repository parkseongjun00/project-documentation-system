# 개발 계획

---

## 0. 일러두기

이 문서는 작업 묶음별 구현·확장 순서를 정한다. 현재 작업의 상태와 확인 범위는 [인수인계](HANDOFF.md)에 기록한다.

---

## 1. 문서 체계

1. 범용 명세와 기능 범위, 작업 순서, 결정 기록의 역할을 정의한다.
2. 보류 과제와 조사 기록의 이관 규칙을 정리한다.
3. 공용 인수인계와 세션별 논의 초안이 함께 동작하도록 운영 규칙을 문서화한다.

---

## 2. 스킬

1. 자료를 읽고 문서 본문을 채우는 초기 절차를 작성한다.
2. 후속 세션에서 사용 사례와 기존 작업 지침을 검토해, 필요한 절차와 프로젝트 규칙의 보존 위치를 정한다.
3. 기존 프로젝트와 비게임 사례에 적용해 본문 작성, 기존 문서 유지, 세션 간 초안 분리를 확인한다.
