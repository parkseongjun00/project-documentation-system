## 1. 필수 작업 순서

> **작성 안내**
>
> - **작업** - Systems.md의 시스템·기능명을 기준으로 필요한 구현·연결·확장·조정 작업을 적는다. 해당 작업에서 만들어지거나 달라질 결과를 알 수 있게 쓴다.
> - **선행 작업·착수 조건** - 먼저 끝나야 하는 작업의 순서 번호와 착수에 필요한 데이터·환경·결정 등을 적는다.
>
> 관련 Systems.md 항목은 표 위나 작업명에 연결하고, 기능 설명과 입력·출력은 반복하지 않는다. 단독 시연이 어려운 준비 작업도 산출물을 이해할 수 있는 단위로 적고, 이를 사용하는 후속 작업에 선행 관계를 표시한다.

작업별 확인 입력·조건, 확인 방법과 기대 결과는 세션의 논의 초안이나 검증 계획에 적는다. 준비 작업은 지금 확인할 산출물과 이후 어느 작업에서 어떤 방법으로 동작을 확인할지도 명시한다. 실제 확인 결과는 해당 작업의 검증 보고에 남긴다.
