## 0. 일러두기

주요 작업 묶음의 구현·확장 순서를 정리한다. 기능 범위와 상세 규칙은 [Systems.md](Systems.md)와 [ProjectSpec.md](ProjectSpec.md)를 따른다.

이미 해온 기반 작업과 이후 확장 작업을 함께 담는다. 장 번호는 작업 묶음의 구분이며 프로젝트 전체의 실행 순서가 아니다. 표의 순서는 각 묶음의 기본 흐름이고, 독립적인 항목은 병행할 수 있다. 실제 진행 상태는 표시하지 않는다.

작업명은 Systems의 시스템·기능명을 기준으로 작성하며, 필요한 구현·연결·확장·조정 작업으로 나눈다.
