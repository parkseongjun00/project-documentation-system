# 시스템·기능 목록

---

## 0. 일러두기

이 문서는 프로젝트의 기능 범위를 훑는 목록이다. 상세 동작과 제약은 [프로젝트 명세](ProjectSpec.md)를 따른다.

---

## 1. 문서 체계

| 기능 | 포함 내용 |
|---|---|
| 문서 역할과 작성 기준 | 문서 지도, 일러두기, 기본 목차, 작성 가이드 |
| 현행 기준 관리 | 프로젝트 명세, 기능 범위, 작업 묶음별 순서 |
| 기록과 이관 | 결정 이력, 보류 과제, 문제별 조사 기록, 인수인계 |
| 세션별 초안 | 세션마다 고유 파일 지정, 담당 파일 갱신, 확정 내용 이관 |

---

## 2. 스킬

| 기능 | 포함 내용 |
|---|---|
| 문서 체계 적용 | 현재 자료와 문서 역할 대응, 필요한 구조 제안 또는 작성 |
| 본문 작성과 갱신 | 사용자 설명과 자료를 반영하고 확정·제안·미정 구분 |
| 결정 질문 정리 | 답에 따라 명세나 범위가 달라지는 질문 제시 |
